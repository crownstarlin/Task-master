🚀 Task Master
Plan. Execute. Dominate.
Task Master is a modern productivity and task-management application designed to help you organize tasks, projects, goals, schedules, and daily activities from one place.
✨ Features
✅ Create, edit, complete, and delete tasks
📅 Calendar view
🎯 Goals and progress tracking
📁 Project management
🔎 Search and filter tasks
🚦 Task priorities
🔁 Recurring task support
📊 Productivity analytics
🔔 Browser notifications
🤖 AI Assistant interface
💾 Automatic local data storage
📤 Export your data
📱 Responsive mobile-friendly design
🌙 Modern dark interface
⚡ Fast — no external dependencies required
🛠️ Technologies
Task Master currently uses:
HTML5
CSS3
JavaScript
Browser LocalStorage
Responsive Web Design
The current version is a single-page application, so there is no complicated installation or build process.
🚀 Run Locally
Clone the repository:
git clone https://github.com/YOUR-USERNAME/task-master.git
Open the project folder:
cd task-master
Then open:
index.html
in your browser.
🌐 Deploy with Vercel
Task Master can be deployed directly to Vercel.
Upload this project to GitHub.
Sign in to Vercel.
Select Add New → Project.
Import your Task Master GitHub repository.
Use a static/Other framework preset.
Leave the build command empty.
Deploy.
Your Task Master app will then have its own public web address.
💾 Data Storage
The current version stores data using the browser's LocalStorage.
This means tasks and settings are saved on the user's device/browser.
Cloud synchronization, user accounts, real-time collaboration, and cross-device data synchronization will require a backend and database.
